# Setup

Run automatically; only stop when blocked.

1. `npm install`
2. Smoke-test OpenAI, Google Maps, Open-Meteo, Tripadvisor, Pandorium
3. Write `.env.local` with your own keys (gitignored; do not commit):

```env
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_CHAT_MODEL=gpt-5.4
OPENAI_IMAGE_MODEL=gpt-image-1.5
GOOGLE_MAPS_API_KEY=
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=
TRIPADVISOR_API_KEY=
TRIPADVISOR_BASE_URL=https://terra.tripadvisor.com/api
PANDORIUM_MCP_URL=https://pandorium.app/mcp
```

4. Implement all features
5. `npm run dev` → http://localhost:3000
