## Minimum dependencies policy

- Use as few dependencies as possible — prefer the platform, stdlib, and existing stack before adding packages.
- Keep the architecture clean: no optional libs “just in case.”
- No React Query, Zustand, or React Hook Form unless a concrete MyDay need appears (App Router + React state + Zod cover profile forms and progressive section loading).
- **Storage: local JSON files under `data/` only. Do not use a database** (no Postgres, MongoDB, Prisma, SQLite server, etc.).

## Mapping to requirements

## Country / region limitations

Availability can change; prefer the alternatives below when building or running from that region.

### Mainland China

| Not available / unreliable | Alternative |
| --- | --- |
| **OpenAI (ChatGPT API)** (`api.openai.com`) | **DashScope (Qwen)** — OpenAI-compatible + native image API |
| **Google Maps Platform** (direct client/server calls) | **AMap (Gaode)** for China maps · or **Google Maps MCP for China** (`GMAPS_MCP_URL` / `GMAPS_MCP_BEARER`) when Google data is still required |
| **npmjs.org** registry (slow or blocked) | **npmmirror** — `https://registry.npmmirror.com` |

### Hong Kong

| Not available / unreliable | Alternative |
| --- | --- |
| **OpenAI (ChatGPT API)** (`api.openai.com`) | **DashScope (Qwen)** — OpenAI-compatible + native image API |
| **npmjs.org** registry (often slow) | **npmmirror** — `https://registry.npmmirror.com` |

Notes:

- Google Maps direct access is generally usable from Hong Kong; use AMap / Maps MCP mainly for mainland China.
- Prefer DashScope as the default LLM for projects targeting mainland China or Hong Kong.

## UX performance

- Target: each section ready within **10s** (matches requirement)
- Fetch in parallel; stream / render as each piece completes — do not wait for all sections
- Always show tips / progress while a section is generating
- Timeouts ≤10s per section (use local fallbacks when an upstream is slow)

## npm install

From **mainland China** and **Hong Kong**, install packages via the Aliyun npmmirror:

```bash
npm config set registry https://registry.npmmirror.com
# or one-off:
npm install --registry=https://registry.npmmirror.com
```

Elsewhere, the default npm registry is fine.

### Explicitly out of scope

Do **not** add or depend on these for MyDay (not in requirements):

- Flights (AviationStack, OpenSky, FlightAware, VariFlight, FAA ASWS, aviationweather.gov)
- Transactional email (Resend / SMTP)
- Pokémon / TCG APIs (TCGdex)
- Embeddings or vector DBs
- Any database server
