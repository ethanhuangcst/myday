# Tech stack & dependencies

MyDay-only stack. **All API keys and secrets live in `.env.local` only** — never commit real key values or `.env.local`. Do not duplicate keys elsewhere (code, other env files, or docs beyond the checklist below).

## Minimum dependencies policy

- Use as few dependencies as possible — prefer the platform, stdlib, and existing stack before adding packages.
- Keep the architecture clean: no optional libs “just in case.”
- No React Query, Zustand, or React Hook Form unless a concrete MyDay need appears (App Router + React state + Zod cover profile forms and progressive section loading).
- **Storage: local JSON files under `data/` only. Do not use a database** (no Postgres, MongoDB, Prisma, SQLite server, etc.).

## UX performance

- Target: each section ready within **10s** (matches requirement)
- Fetch in parallel; stream / render as each piece completes — do not wait for all sections
- Always show tips / progress while a section is generating
- Timeouts ≤10s per section (use local fallbacks when an upstream is slow)

## Secrets & env (single source of truth)

Copy into `.env.local`. This is the **only** place API keys are stored and listed.

```bash
# Required keys
OPENAI_API_KEY=
GOOGLE_MAPS_API_KEY=
TRIPADVISOR_API_KEY=

# Non-secret config (URLs / models — no keys)
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_CHAT_MODEL=gpt-5.4
OPENAI_IMAGE_MODEL=gpt-image-1.5
PANDORIUM_MCP_URL=https://pandorium.app/mcp
TRIPADVISOR_BASE_URL=https://terra.tripadvisor.com/api
```

| Variable | Used by |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI chat + image |
| `GOOGLE_MAPS_API_KEY` | Server-side Maps/Places/Geocoding/Directions; client Maps JS / Embed via server-issued config or same key restricted by HTTP referrer (do **not** add a second Maps key env) |
| `TRIPADVISOR_API_KEY` | Tripadvisor Terra (`X-API-Key` header) |

Open-Meteo and Pandorium MCP need **no** API key.
