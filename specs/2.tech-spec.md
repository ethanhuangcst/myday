## Minimum dependencies policy

- Use as few dependencies as possible — prefer the platform, stdlib, and existing stack before adding packages.
- Keep the architecture clean: no optional libs “just in case.”
- No React Query, Zustand, or React Hook Form unless a concrete MyDay need appears (App Router + React state + Zod cover profile forms and progressive section loading).
- **Storage: local JSON files under `data/` only. Do not use a database** (no Postgres, MongoDB, Prisma, SQLite server, etc.).

## UX performance

- Target: each section ready within **10s** (matches requirement)
- Fetch in parallel; stream / render as each piece completes — do not wait for all sections
- Always show tips / progress while a section is generating
- Timeouts ≤10s per section (use local fallbacks when an upstream is slow)
