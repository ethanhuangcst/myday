# MyDay Web App
- A daily planning web app integrating capabilities such as ChatGPT LLM (Chat & Image Generation), Google Maps, TripAdvisor, Weather, and Zodiac insights
- That helps users start their day with personalized recommendations.

## Overview
- Entry screen that allows users to enter their personal information and save it as their profile
- Provide zodiac insights
- Based on the user's profile, weather, today's mood, and zodiac insights, recommend today's outfit
- List nearby restaurants based on the user's location (auto-detected; manual entry if unavailable)
- Highlight TripAdvisor reviews for the restaurants if any

## Requirement
### Profile List
- A grid view to display all existing profiles
- Each profile displays as a card, with name and photo
- Click a profile card to enter "Plan my day"
- Click "Create a new profile" button to enter "Create a new profile"

### Create a new profile
- User enters personal details
  - Name
  - Gender
  - Date of birth
  - Upload a photo of yourself (optional)
  - Height
  - Weight
  - Occupation
- Clicks "Save" button; the profile will be saved

### Plan my day
- "My profile" section: allow the user to view/edit the profile information, with a "Delete" function (confirmation required)
- "What am I into?" section: 
  - Get the current location (default: browser geolocation; manual entry if unavailable)
  - User manually enters "My mood now", e.g., "excited"
  - User manually enters "What I'm doing today", e.g., "travelling"
- Click "Plan my day" button to enter "My day plan"

### My day plan
- Header section 
  - "Hello, {name}" + photo if any
  - Display personal information with auto-calculated age and zodiac sign
- Weather section: query weather for the current location
- Zodiac insights section
  - Provide detailed personal zodiac insights
  - Based on the information the user entered for "What am I into" on the previous screen, and the zodiac insights fetched from zodiac api/mcp, use LLM to give specific recommendations, such as "Things to do / Things to avoid", and any other fun recommendations AI could think of.
- Outfit Recommendation section
  - Based on weather, "My mood now", "What I'm doing today", and zodiac insights, use LLM to generate outfit recommendation (display as text)
  - Use image LLM to generate a portrait with today's outfit recommendation
    - If the user uploaded a photo, generate a highly realistic avatar based on that photo
    - If not, generate one from the user's profile information
    - It should match the outfit recommendation generated by LLM
  - Ensure the image is properly displayed with the visibility of the whole body.
  - Complete the generation in 20 seconds, deduce image size an quality to improve performance
  - Do not display "Timeout", if it takes longer time, display more time is needed

- Display **What to Eat Today** recommendations:
  - Let the user choose a cuisine (Japanese, Spanish, Italian, fast food, Cantonese, etc.)
  - Call the map API/MCP to find suitable restaurants within 3 km of the current location
  - Display results as a list, sorted by distance
  - If that restaurant is listed on TripAdvisor, display a TripAdvisor icon next to it, and a brief review summary
  - On restaurant click, open a floating popup for restaurant detailed information, with an embedded map showing the restaurant location with navigation, and close / Escape / backdrop

### Performance and user friendly
- Always show user tips and progress when content is being generated
- When displaying the content, do not wait until all contents are ready — display the content piece by piece when it's ready
- The content for each section should be generated within 20 seconds
